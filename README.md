# Amee Chhatbar — Portfolio

Personal portfolio built with React, TypeScript and Vite, with an interactive terminal (and a few games) built in.

**Live:** https://ameechhatbar.github.io

## Run locally

```bash
cd frontend
npm install
npm run dev
```

## Update content

All text — experience, projects, skills, achievements — lives in [`frontend/src/data/portfolio.ts`](frontend/src/data/portfolio.ts). The resume is `frontend/public/Amee_Chhatbar_Resume.pdf`.

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages via [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
